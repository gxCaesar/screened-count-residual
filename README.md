# Screened Count Residual: Spatial Threshold Calibration for Virtual Immunostaining

Standalone, CPU-verifiable reference implementation (`v2.1.0`), worked calibration example, split manifests, and complete audited Source Data and per-unit result tables for gauge-fixed Screened Count Residuals across 20 pretrained virtual-staining generator instances and six cohorts spanning five human and murine organ systems (`HEMIT`, `Harvard Orion-CRC`, `HER2match`, `MIST` four-IHC, `DeepLIIF` Lung/Bladder/Breast, and `Mouse Brain and Dura Mater`).

## Repository Layout

- `s2/`: Complete transitive import closure of core operators (`query_relation_reconstruction.py`, `query_relation_count_objective.py`), plug-and-play universal residual head (`screened_universal_head.py`), generator adapters (`backbone_zoo.py`), single-cell spatial proximity and duplicate-free time-to-recurrence survival evaluator (`clinical_cell_survival.py`), confirmatory campaign runners (`run_hemit_multibackbone_cell.py`, `run_orion_multibackbone_survival.py`, `run_her2match_dab_campaign.py`), expansion runners (`run_nm_*.py`, `run_push*.py`), `v2.0.0` flagship runners (`run_nv2_n1_*.py` through `run_nv2_n8_brain_dura_labelfree.py`), and `v2.1.0` mechanistic and scaling runners (`run_v21_p0_ecount_zm_and_loc.py`, `run_v21_p1_mist_loc_and_zm.py`, `run_v21_p2_orion40_atlas_and_xdom_curve.py`).
- `manifests/`: Sanitized region-disjoint HEMIT split manifest (`split-manifest.json`), patient-disjoint Orion 5-fold manifest (`orion-patient-cv-manifest.json`), and de-identified 40-patient Orion-CRC clinical survival table (`orion_crc40_clinical_and_summary.csv`).
- `results/source_data/`: Complete standalone tabular Source Data bundle covering all 18 display items (`Fig. 1--6`, `Extended Data Fig. 1--10`, `Supplementary Fig. 1--2`) and `PANEL_TO_SOURCE_DATA.csv` (all 57 referenced tabular CSVs covering 270 panels resolved locally; 4 optional binary NPZ visualization caches remain in the full repository).
- `results/tables/`, `results/expansion/`, `results/nm_nature_push/`, `results/nature_v2/`, and `results/nature_v21/`: Complete per-unit confirmatory CSV tables across all 20 generator instances (`all20_universal_backbones.csv`, `determinism_480_parity.csv`), 19-arm comparator matrix with zero-mean unscreened `E_count_zm` and run provenance (`v21_comp19_all20.csv`), MIST localization and consecutive-section shift diagnostics across 45 marker-slide evaluations and 43 distinct slides (`v21_p1_localization_and_shift.csv`, `v21_p1_mist_perslide_44.csv`), full 5-fold all-40-patient 335,597-nucleus Orion single-cell atlas (`v21_p2_orion40_5fold_atlas.json`, `v21_p2_orion40_atlas_summary.csv`), Beijing-to-Dutch sample-efficiency and slide-budget curves (`v21_p2_xdom_budget_curves.csv`), unified full-tile Orion survival (`nv2_n1_orion_survival_unified.csv`), mechanistic XAI (`nv2_n2_mechanistic_xai.json`), mosaic seam continuity (`nv2_n4_wsi_seam_composition.json`), and mouse brain and dura mater (`nv2_n8_brain_dura_labelfree.json`).
- `scripts/reproduce_journal_results.py`: Deterministic CPU verification recomputing all 20-generator confirmatory comparisons, exact two-sided Wilcoxon signed-rank tests (SciPy `method="exact"` omitting exact-zero ties) across 19-arm `E_count_zm` subsets, 45 MIST marker-slide evaluations and collapsed 43 distinct slides, and the 40-patient 335,597-nucleus Orion single-cell atlas directly from CSV/JSON, plus 100% file resolution across all 57 tabular Source Data CSVs referenced by the 270 panels in `results/source_data/PANEL_TO_SOURCE_DATA.csv`.
- `scripts/example_tile_calibration.py`: Self-contained CPU worked example fitting a Screened Count Residual head, reloading its checkpoint, and verifying exact pre-clipping zero-DC conservation and conjugate-gradient convergence.
- `tests/`: Self-contained unit test suite verifying zero-DC gauge invariance, spectral solver accuracy, isolated false-positive count adjoint sign, Ruifrok--Johnston H-DAB channel isolation and strict cutoff boundary, duplicate-free Harrell C-index bootstrap, worked tile calibration, campaign CLI imports, and confirmatory table reproduction.
