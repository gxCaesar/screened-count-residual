# Screened Count Residual: Spatial Threshold Calibration for Virtual Immunostaining

Standalone, CPU-verifiable reference implementation (`v2.2.1`), worked calibration example, split manifests, and complete audited Source Data and per-unit result tables for gauge-fixed Screened Count Residuals across 20 pretrained virtual-staining generator instances, 20 comparator arms (including zero-mean unscreened `E_count_zm` and pure local Laplacian flux `L_count` in unified single-run 6-arm receipts across all 20 generators), 5-architecture 40-patient 335,597-nucleus Orion-CRC phenotyping, independently hematoxylin-aligned MIST 4-IHC with strict 1:1 Hungarian matching, and six cohorts spanning five human and murine organ systems (`HEMIT`, `Harvard Orion-CRC`, `HER2match`, `MIST` four-IHC, `DeepLIIF` Lung/Bladder/Breast, and `Mouse Brain and Dura Mater`).

## Repository Layout

- `s2/`: Complete transitive import closure of core operators (`query_relation_reconstruction.py`, `query_relation_count_objective.py`), plug-and-play universal residual head (`screened_universal_head.py`), generator adapters (`backbone_zoo.py`), single-cell spatial proximity and duplicate-free time-to-recurrence survival evaluator (`clinical_cell_survival.py`), confirmatory campaign runners (`run_hemit_multibackbone_cell.py`, `run_orion_multibackbone_survival.py`, `run_her2match_dab_campaign.py`), expansion runners (`run_nm_*.py`, `run_push*.py`), `v2.0.0` runners (`run_nv2_n1_*.py`--`run_nv2_n8_*.py`), `v2.1.0` runners (`run_v21_p0_*.py`--`run_v21_p2_*.py`), and `v2.2.0` runners (`run_v22_q1_lcount_all20.py`, `run_v22_q2_orion40_unseen_atlas.py`, `run_v22_q3_mist_align_and_gate.py`).
- `manifests/`: Sanitized region-disjoint HEMIT split manifest (`split-manifest.json`), patient-disjoint Orion 5-fold manifest (`orion-patient-cv-manifest.json`), and de-identified 40-patient Orion-CRC clinical survival table (`orion_crc40_clinical_and_summary.csv`).
- `results/source_data/`: Complete standalone tabular Source Data bundle covering all 18 display items (`Fig. 1--6`, `Extended Data Fig. 1--10`, `Supplementary Fig. 1--2`) and `PANEL_TO_SOURCE_DATA.csv` (all 66 referenced tabular CSVs covering 271 panels resolved locally; 4 optional binary NPZ visualization caches remain in the full repository).
- `results/tables/`, `results/expansion/`, `results/nm_nature_push/`, `results/nature_v2/`, `results/nature_v21/`, and `results/nature_v22/`: Complete per-unit confirmatory CSV tables across all 20 generator instances (`all20_universal_backbones.csv`, `determinism_480_parity.csv`), unified single-run 20x6 and 20-arm comparator matrices (`v22_comp20_all20.csv`, `v22_q1_6arm_parity_audit.csv`), 5-architecture 40-patient 335,597-nucleus Orion-CRC atlas and per-patient scores (`v22_q2_orion40_5arch_atlas.csv`, `v22_q2_orion40_5arch_per_patient.csv`), independently hematoxylin-aligned MIST 1:1 Hungarian, per-slide, pre-alignment ODS/burden, and gate tables (`v22_q3_mist_align_hungarian.csv`, `v22_q3_mist_perslide_aligned.csv`, `v21_p1_mist_prealign_ods_burden.csv`, `v22_q3_mist_slide_gate.csv`), exhaustive 21+1-slide Dutch HER2match Pre-Deployment Accept/Abstain Clinical Gate (`v22_q3_xdom_21slides_gate.csv`), and master JSON receipts (`V22_MASTER_SUMMARY.json`).
- `scripts/reproduce_journal_results.py`: Deterministic CPU verification recomputing all 20-generator confirmatory comparisons, unified 20/20 single-run 6-arm exact Wilcoxon tests (`S_count` vs `L_count` & SMHI vs `E_count_zm`), all five architectures' 40-patient 335,597-nucleus Orion exact Wilcoxon tests directly from `v22_q2_orion40_5arch_per_patient.csv`, independently aligned MIST 43-distinct-slide exact Wilcoxon tests and 95-draw full-rule gate counts (`calib_n_pos_tiles >= 5`), exhaustive 21-slide Beijing-to-Dutch clinical accept/abstain full-rule gate counts across all four operating points (`0.25, 0.30, 0.35, 0.40`), pre-alignment Fig. 6j,k MIST correlation sign, and 100% file resolution across all 66 tabular Source Data CSVs referenced by the 271 panels in `results/source_data/PANEL_TO_SOURCE_DATA.csv`.
- `scripts/example_tile_calibration.py`: Self-contained CPU worked example fitting a Screened Count Residual head, reloading its checkpoint, and verifying exact pre-clipping zero-DC conservation and conjugate-gradient convergence.
- `tests/`: Self-contained unit test suite verifying zero-DC gauge invariance, pure algebraic zero-mean `L_count` conservation, spectral solver accuracy, isolated false-positive count adjoint sign, Ruifrok--Johnston H-DAB channel isolation and strict cutoff boundary, duplicate-free Harrell C-index bootstrap, worked tile calibration, campaign CLI imports, and confirmatory table reproduction.
